## Option 2: The "Tech Stack" (Developer Focused)
*Best for: Engaging with the Rust, Tauri, and React communities.*

**Just shipped: A Windows Context Menu Manager built with Tauri 2.0 & Rust! 🦀⚛️**

I wanted to build a desktop tool that felt native, performed instantly, and looked great. This project was the perfect opportunity to dive deep into the **Tauri 2.0** ecosystem.

**Under the hood:**
*   **Backend**: Rust (using `winreg` for safe registry manipulation).
*   **Frontend**: React 18 + TypeScript + Tailwind CSS.
*   **Architecture**: The app runs with minimal resource usage and communicates safely with the OS layer.

One of the coolest challenges was implementing the "Auto Icon Detection" which extracts icons directly from executables to display in the UI.

Code is open source and I welcome contributions! Check it out if you're interested in Windows internals or Tauri development.
